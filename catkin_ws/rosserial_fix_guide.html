ROS Noetic · rosserial

Arduino 同步
修復指南

rosserial 協定版本不相容問題的完整解決流程

發生的錯誤
[ERROR] Unable to sync with device; possible link problem or link software version mismatch such as hydro rosserial_python with groovy Arduino [INFO] Requesting topics... [ERROR] Unable to sync with device; ...

根本原因

Arduino 上燒錄的 rosserial 函式庫版本過舊（Groovy／Hydro 時代），與 Raspberry Pi 上的 rosserial_python 0.9.2（Noetic） 握手協定不相容，導致無法建立連線。

修復步驟
✓

在樹莓派產生 Noetic 版函式庫

此步驟已完成。產生的函式庫已打包於：

路徑
/root/catkin_ws/ros_lib_noetic.tar.gz

此包內含你專案的自訂訊息（LaneData、TurnDetect）。

2

下載到你的電腦

在你的電腦終端機執行 scp 下載：

Terminal
scp pi@<樹莓派IP>:~/catkin_ws/ros_lib_noetic.tar.gz ~/Downloads/

解壓縮：

Terminal
cd ~/Downloads tar -xzf ros_lib_noetic.tar.gz
3

替換 Arduino IDE 的 ros_lib

先刪除舊的 ros_lib，再將新的放入 Arduino libraries 資料夾：

Windows
C:\Users\你的名字\Documents\Arduino\libraries\ros_lib\
macOS / Linux
~/Arduino/libraries/ros_lib/
⚠️

務必先完整刪除舊的 ros_lib 資料夾，再放入新的，否則舊檔案可能殘留造成衝突。

4

確認 sketch 鮑率一致

打開 Arduino IDE，確認 sketch 裡的鮑率與 launch file 相同（115200）：

Arduino (.ino)
// 確認這行的數值是 115200 nh.getHardware()->setBaud(115200);
💡

launch file 中 baud 參數設定為 115200，Arduino sketch 必須相同。

5

重新上傳 sketch 到 Arduino Mega

重開 Arduino IDE（讓新函式庫生效），然後對你的 Arduino Mega 執行 Verify → Upload。

驗證成功

測試連線

燒錄完成後，在樹莓派執行以下指令：

zsh
source /opt/ros/noetic/setup.zsh source /root/catkin_ws/devel/setup.zsh rosrun rosserial_python serial_node.py \ _port:=/dev/ttyUSB0 _baud:=115200

看到以下訊息代表成功：

[INFO] registered publisher on /topic_name ...
