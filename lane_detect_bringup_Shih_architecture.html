Pi ↔ Arduino Mega 的 USB 序列橋接

Shih 變體的特色

相對標準 bringup 的調校差異

節點架構與 lane_detect_bringup.launch 完全相同，差別只在 lane_controller_fuzzy / lane_detect_node 的參數 —— Shih 版更「積極」：速度更快、轉彎更猛、招牌偵測更早觸發。

不能搞錯的約定

關鍵契約

驅動 topic 是 arduino_vel（不是 /cmd_vel）。控制器發它、Mega 韌體訂閱它。要改名 Python 與 .ino 都得一起改。
只用到 linear.x 與 angular.z。Mega 用 LINEAR_SCALE=289.4 / ANGULAR_SCALE=23.8 換成左右輪 RPM。
序列鮑率必須一致：115200。launch 的 serial_node 與韌體 setBaud(115200) 兩端要對得上。
自訂訊息：LaneData(offset, angle)、TurnDetect(turn_direction, pixel_size, offset)。改 .msg 後要重新 catkin_make 並 source devel/setup.zsh。
